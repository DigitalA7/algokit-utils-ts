# 5. Versions et limites

Le dépôt signale des guides de migration distincts pour les versions 7 et 8. Même si les fonctionnalités annoncées sont proches, la version d’algosdk et la compatibilité de l’arbre de dépendances changent.

Les utilitaires facilitent l’intégration mais ne garantissent pas à eux seuls la sécurité d’une DApp : contrôle des signatures, validation des montants, idempotence et gestion des erreurs doivent être traités au niveau du produit.

La licence et les détails de gouvernance doivent être relus dans les fichiers du dépôt avant redistribution. Le dernier contrôle actif doit suivre la suite de tests et les consignes officielles, sans les déclarer exécutés ici.
